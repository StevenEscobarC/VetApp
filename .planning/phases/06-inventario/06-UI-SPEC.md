# Phase 6 — UI Design Contract

> Visual and interaction contract. Generated by gsd-ui-researcher, to be verified by gsd-ui-checker. Mode: no questions asked; every value derived from `06-CONTEXT.md` (D-01..D-16, unchanged), `06-RESEARCH.md`, `.planning/design/DESIGN-REFERENCE.md` and the locked Phase 1-5.1 UI-SPECs. Structure and level of detail follow `05.1-UI-SPEC.md`.

## Scope

**Tokens LOCKED from Phases 1-5.1** (`lib/core/theme/*`). This phase redefines no font, size, weight, spacing or color token and adds **no shared widget to `lib/core/widgets`**. New widgets are feature-local (`lib/features/inventory/presentation/widgets/`) and are built only from existing tokens and core widgets. `AppFilterChip` is reused as-is (its doc already reserves it for Inventario; never fork it).

**Decisions consumed (not re-asked):** D-01..D-16 from `06-CONTEXT.md`; stack and navigation from `06-RESEARCH.md` (top-level `/inventario` routes outside the shell, Más row, Inicio card, `ControlEscritura` / `asegurarEscritura` / `LimitePlanSheet` for read-only, `Compartidor` for the order text, `formatearCop` to be created, no new packages); the lock treatment, `warningBg` banner pattern, 64px `surfaceMuted` icon circle, disabled-without-opacity rule, pill badges and "Agregar más detalles" disclosure from `05.1-UI-SPEC.md` / `05-UI-SPEC.md`; extended FAB "Nuevo cliente" precedent (`clientes_list_screen.dart`).

**Guiding rules**
1. **Ten seconds, one hand (CONTEXT specifics).** Every frequent action (descontar 1, sumar compra, corregir conteo, dar de alta) is reachable with the thumb in the lower two thirds of the screen, with numeric keypad, 48dp targets and no more than 3 taps after opening the screen.
2. **Status is never color-only.** Every badge is icon + text; quantities are always numbers, never only a bar or a color.
3. **The ledger is the truth.** The UI never computes a new quantity as authority: it sends a `delta` and renders the `cantidad_resultante` the server returns. Previews ("Quedarán 14") are courtesy only.
4. **Undo, don't punish.** Small adjustments apply immediately and can be undone; only big ones (> 10 units) ask first. Nothing is ever deleted: archive hides, history stays.
5. **Plan and role are different locks.** Read-only (plan, D-14) uses the Phase 5.1 lock-icon treatment and `LimitePlanSheet`. Role limits (admin-only fields, D-13) are shown as read-only values with an explanatory helper, never with the lock icon.

**In scope (surfaces):**
1. `InventarioScreen` — `/inventario` (list, search, filters, quick adjust, order by WhatsApp).
2. `ProductoFormScreen` — `/inventario/nuevo` and `/inventario/:id/editar` (one-step create; edit).
3. `ProductoDetailScreen` — `/inventario/:id` (summary, adjust, movement history, archive).
4. `AjusteSheet` — modal bottom sheet for any adjustment beyond "−1".
5. `StockBajoCard` on Inicio (only when at least one product is low).
6. Más row "Inventario" with "N bajos" pill.
7. Read-only (plan) lock treatment on every write control of the above.

**Out of scope (render nothing):** descuento al registrar dosis / selector "Producto de inventario" (D-05), facturación, IVA, proveedores y órdenes de compra, lotes múltiples, código de barras, conversión de presentaciones, multi-bodega, push notifications, offline queue (D-12), restore of archived products, "ver archivados", autocomplete from the biologicals catalog (cut, RESEARCH A6), free-text note on adjustments, dark-mode re-derivation (Phase 8).

## Spacing Scale

Reused from `AppSpacing`, multiples of 4 only.

| Token | Value | Usage this phase |
|-------|-------|------------------|
| xs | 4px | Icon-to-label gap inside badges, gap between name and meta line in a row, badge vertical padding |
| sm | 8px | Gap between row buttons, between badges, between chips, between sheet buttons, badge horizontal padding |
| md | 16px | Screen horizontal padding, `AppCard` padding, gap between rows/cards, strip padding, form field gap |
| lg | 24px | Gap between sections (detail), sheet top/bottom padding, gap above primary action in sheet/form |
| xl | 32px | Bottom of scroll content (+ safe area), empty-state vertical offset |
| 2xl | 48px | Touch-target minimum: row buttons (−1, +), chips, sheet buttons, form buttons, steppers |
| 3xl | 64px | Icon circle in empty states (`surfaceMuted` circle, 32px icon) |

**Exceptions:** 48dp touch targets (`AppSpacing.touchTarget`) for every tap target; 56dp min height for the Más row and the Inicio card (same as sibling rows); list scroll content keeps **88px bottom padding** (56 FAB + 16 margin + 16 breathing room, local constant, multiple of 4) so the last row is never covered by the FAB; badge height 28px (compact, same as `DosisEstadoChip`); icon circle 64px with 32px icon (same local constant as 5 / 5.1); `MovimientoTile` leading circle 40px; inline progress spinner 20px; standard Material icons 24px. No other exceptions.

## Typography

Same 4 roles, same 2 weights. **No new sizes or weights.**

| Role | Size | Weight | Line Height |
|------|------|--------|-------------|
| Body | 16px | 400 (Figtree) | 1.5 |
| Label | 14px | 600 (Figtree) | 1.5 |
| Heading | 20px | 400 (Caprasimo) | 1.2 |
| Display | 28px | 400 (Caprasimo) | 1.2 |

**Usage mapping:**
- **Display (28px):** the product **quantity** number in a list row and in the detail header (the focal number of the phase). Scales down with `FittedBox` for 7-digit values ("1.000.000").
- **Heading (20px):** `AppTopBar` titles, product name in rows and in the detail header, section headings ("Historial de movimientos"), sheet titles, empty-state titles.
- **Body (16px):** helper sentences, search text, field values, snackbar text, movement titles ("+10 frascos · Compra"), dialog bodies, strip/card message.
- **Label (14px/600):** badges, chips, unit label under the quantity ("frascos"), meta line ("Mínimo 2 · Vence 15/12/2026"), field labels, helper lines, movement subtitles, "Ver bajos", key labels in the detail card.

**Focal points:** list row — the quantity (Display) then the product name (Heading). Detail — quantity, then the one accent CTA "Agregar stock". Sheet — the numeric field, then "Aplicar ajuste".

**Stock state style map (color is never the sole cue — icon + text always present):**

| State | Rule | Fill | Text | Icon (16px) | Border | Label |
|-------|------|------|------|-------------|--------|-------|
| Agotado | `cantidad == 0` and `minimo > 0` | `destructive` | `onDestructive` | `error_outline` (`onDestructive`) | none | "Agotado" |
| Bajo | `0 < cantidad < minimo` | `warningBg` | `primaryText` | `trending_down` (`primaryText`; the `warning` hue only on the border, per the 5.1 checker note on icon contrast) | `warning` at 40 % | "Bajo" |
| Vencido | `vencimiento < hoy` (Bogotá) | `destructive` | `onDestructive` | `event_busy` (`onDestructive`) | none | "Vencido" |
| Vence pronto | `0 <= días <= 30` | `warningBg` | `primaryText` | `schedule` (`primaryText`) | `warning` at 40 % | "Vence pronto" |
| Normal | none of the above | no badge | — | — | — | — |

Notes: "Agotado" is a sub-case of low (counted in "Bajos", D-07); a product with `minimo = 0` and `cantidad = 0` shows no badge (it is never low). Max two badges per row (one stock badge + one vencimiento badge), in that order; they wrap.

Pill shape: radius `radiusLg`, height 28px, padding 8px horizontal, icon 16px + Label, 4px gap (same family as `DosisEstadoChip` compact). Semantics label = badge text.

Movement direction in history is conveyed by the sign in the text ("+10", "−3") and the arrow icon; the icon tone is `success` for entries and `textSecondary` for exits, never red (an exit is normal, not an error).

## Layout & Component Patterns

### 1. Entry points (navigation, RESEARCH Pattern 6)

- **Más row "Inventario"** — `AppCard` row, min height 56, `Icons.inventory_2_outlined`, Body "Inventario", trailing pill "N bajos" (`warningBg`, `trending_down`, Label; singular "1 bajo") **only when `bajos > 0`**, then chevron. Placed directly after "Mi plan" and before "Recordatorios" (operational group: Inventario, Recordatorios, Protocolos de vacunación). The pill is `Flexible` and wraps at large text scales. Loading / error: row without pill (still tappable). Tap → `context.push('/inventario')`. Visible to every vet.
- **Inicio `StockBajoCard`** — below `VacunasPendientesCard`. Spec in §6. Tap → `context.push('/inventario?filtro=bajos')`.
- The screens are top-level routes (no bottom nav on them); back returns to the origin tab.

### 2. InventarioScreen (`/inventario`)

`AppTopBar(title: 'Inventario')`. Fixed header (does not scroll): 16px page padding, then top to bottom:

1. **Search** — `AppTextField` (`hideLabel`, `prefixIcon: Icons.search`, hint "Buscar producto", `textCapitalization: sentences`). Filters the already-loaded list **locally on each keystroke** (case-insensitive substring on the name; no accent folding in this phase). Semantics label "Buscar producto".
2. **Filter chips** — `Wrap`/row of `AppFilterChip`, 8px gap, 48dp: **"Todos"**, **"Bajos (N)"**, **"Vence pronto (N)"** (counts from the loaded list; the count is omitted when 0: "Bajos"). Single-select. "Vence pronto" includes already expired products (they carry the "Vencido" badge).

Scrolling area (`ListView`, 16px horizontal padding, 16px gap between items, 88px bottom padding, `RefreshIndicator` → invalidates list + resumen):

3. **Alert strip** (`ResumenBajosStrip`) — only when filter = "Todos", search is empty and `bajos > 0`: `warningBg` container, 1px `border`, radius `radiusMd`, 16px padding, min height 48: `trending_down` 24px (`primaryText`) + Label "{N} productos con stock bajo" + trailing `TextButton` "Ver bajos" (48dp) which selects the "Bajos" chip. Not dismissible (it is the same fact as the chip; it simply disappears when 0).
4. **"Pedir por WhatsApp"** — only when filter = "Bajos" and there is at least one low product: full-width `AppButton` outline, 48dp, WhatsApp / share icon treatment. Below it, Label `textMuted` helper "Pedimos lo necesario para llegar al doble del mínimo." Tap builds the text (RESEARCH `mensajePedidoStock`: `minimo × 2 − stock`, same A–Z order as the list) and opens the system share sheet with no recipient (D-11). Share failure → snackbar "No pudimos abrir el menú de compartir." **Never locked by read-only** (sharing is not a write).
5. **Product rows** (`ProductoFila`) — see §2.1. Default order **A–Z by name** in every filter except "Vence pronto", which is ordered by `vencimiento` ascending (soonest / already expired first).

**Floating action button:** extended FAB, accent, `Icons.add` + **"Nuevo producto"**, same pattern as "Nuevo cliente". Tap → `asegurarEscritura` pre-check, then `context.push('/inventario/nuevo')`. In read-only (plan) the icon becomes `Icons.lock_outline`, size and variant unchanged, semantics "Nuevo producto, bloqueado, solo lectura", tap opens `LimitePlanSheet` (LP004).

**Entry parameter:** `?filtro=bajos` preselects the "Bajos" chip. Any other entry starts on "Todos". Filter and search are local screen state (reset when leaving the screen).

#### 2.1 ProductoFila

`AppCard`, `surface`, 16px padding, whole card tappable (min height 48) → `context.push('/inventario/{id}')`. Layout:

- **Row A:** `Expanded` Column — product name (Heading, max 2 lines, ellipsis) over meta line (Label `textMuted`): "Mínimo {m}" and, only when the product has an expiry, " · Vence {dd/mm/aaaa}". At the end, right-aligned quantity block: quantity (Display, thousands separator, `FittedBox` scaleDown) over unit label (Label `textSecondary`, plural-aware: "1 frasco" is shown as number "1" + "frasco", otherwise "frascos").
- **Row B (8px below):** `Expanded` `Wrap` of `InsigniaStock` badges (8px gap) at the start, and `AjusteRapidoBotones` at the end.
- **`AjusteRapidoBotones`** (D-09): two square 48×48dp buttons, 8px gap, thumb-side (right):
  - **"−1"** — outline style, `Icons.remove` + Label "1" (reads as "−1"). Applies a delta of −1 with motivo **Uso** immediately, no sheet.
  - **"+"** — outline style, `Icons.add`. Opens `AjusteSheet` in entry mode with motivo **Compra** preselected and the numeric keypad open.
  - Quantity `0`: "−1" is disabled (no opacity: `surfaceMuted` fill, `placeholder` icon), semantics "Descontar 1, no hay stock".
  - While an RPC for this row is in flight both buttons are disabled and the pressed one shows a 20px `CircularProgressIndicator` (prevents double-tap bursts).
  - Read-only (plan): both icons become `Icons.lock_outline`, size / variant unchanged, tap opens `LimitePlanSheet` (LP004); semantics "Descontar 1, bloqueado, solo lectura" / "Agregar stock, bloqueado, solo lectura".
- Tapping the row (outside the buttons) opens the detail. The quantity is **not** a separate tap target.
- Semantics for the card: "{nombre}, {n} {unidad}, mínimo {m}, {badges}, {vence}. Abrir detalle."

#### 2.2 Adjustment feedback (snackbar, D-09 / D-12)

`SnackBarBehavior.floating`, 6-second duration (sits above the FAB), one at a time (a new adjustment replaces the previous snackbar, so **Deshacer always refers to the last adjustment shown**). Text Body, action "Deshacer" (48dp).

| Case | Snackbar text | Action |
|------|---------------|--------|
| −1 quick | "Descontaste 1 {unidad} de {producto}. Ahora hay {m}." | **Deshacer** |
| Compra ≤ 10 | "Agregaste {n} {unidad} a {producto}. Ahora hay {m}." | **Deshacer** |
| Uso / Vencido o dañado ≤ 10 | "Descontaste {n} {unidad} de {producto}. Ahora hay {m}." | **Deshacer** |
| Conteo with |delta| ≤ 10 | "Stock de {producto} corregido a {m}." | **Deshacer** |
| Any adjustment with |delta| > 10 (after the confirm dialog) | "Ajuste aplicado a {producto}. Ahora hay {m}." | none (D-09: undo only for the rest; correct it with a new adjustment) |
| Deshacer succeeded | "Ajuste deshecho. Ahora hay {m}." | none |
| Deshacer rejected (`IN001`: stock changed meanwhile) | "El stock cambió. Ajusta la cantidad manualmente." | none |
| No connection (D-12) | "Sin conexión. El ajuste no se guardó. Inténtalo de nuevo cuando tengas señal." | none |
| `IN001` on quick −1 | "No hay suficiente stock para ese ajuste. Actualiza la lista." | none |
| `IN002` | "Ese producto ya no está disponible. Actualiza la lista." | none |
| Other | "No pudimos completar la operación. Intenta de nuevo." | none |

Quantities in text use `{n}` with thousands separator. `{unidad}` follows the plural rule of §Copywriting. No optimistic UI: the quantity changes when the server answers (list keeps old data during refresh, `skipLoadingOnRefresh`).

### 3. AjusteSheet — any adjustment beyond "−1" (INV-03, D-09)

Modal bottom sheet: `showModalBottomSheet`, `isScrollControlled: true`, drag handle, top radius `radiusLg`, `surface` fill, 24px padding, resizes above the keyboard, primary button pinned below the scroll area. Entry points: the row "+" (preselect **Compra**), the detail "Agregar stock" (preselect **Compra**) and the detail "Ajustar cantidad" text action (preselect **Conteo**, §5). Top to bottom:

1. Heading **"Ajustar stock"**; Body `textSecondary` "{producto} · hay {n} {unidad}".
2. **Motivo** — Label "Motivo" then `Wrap` of single-select `AppFilterChip` (one always selected): **"Compra"**, **"Uso"**, **"Vencido o dañado"**, **"Conteo"** (D-09). Direction is implied by the motivo: Compra = entra; Uso and Vencido o dañado = sale; Conteo = the user types the real count and the delta is computed.
3. **Cantidad** — a row: 48dp `Icons.remove` stepper button, `AppTextField` (numeric, `digitsOnly`, `maxLength: 7`, centered, `autofocus`, select-all on focus), 48dp `Icons.add` stepper button (±1 per tap; in Conteo too). Field label by motivo: Compra "Cantidad que entra", Uso / Vencido o dañado "Cantidad que sale", Conteo "Cantidad contada" (prefilled with the current quantity; the other motivos start empty).
4. **Preview** (Label, below the field, live): "Quedarán {m} {unidad}". Invalid states replace it with an error line (field `errorText` style, icon + text):
   - empty or 0 (non-Conteo): "Escribe una cantidad mayor que 0."
   - exit larger than stock: "No puedes dejar el stock por debajo de 0." (D-04)
   - Conteo equal to the current quantity: "Es la misma cantidad que hay ahora."
   - above 1.000.000: "La cantidad máxima es 1.000.000."
   "Aplicar ajuste" is disabled while any of these holds (no opacity: `surfaceMuted` fill, `placeholder` text).
5. **Actions** (24px above, stacked, 8px gap, 48dp): primary accent **"Aplicar ajuste"** (`isLoading` while the RPC runs; field and chips disabled meanwhile) and `TextButton` **"Cancelar"**.

**Large adjustment (|delta| > 10, D-09):** tapping "Aplicar ajuste" first opens an `AlertDialog`: title **"¿Confirmas este ajuste?"**; body "Vas a {sumar|restar} {n} {unidad} {a|de} {producto}. Quedarán {m}."; actions primary **"Confirmar ajuste"** and text **"Revisar"** (back to the sheet with the data kept). Adjustments with |delta| ≤ 10 apply directly.

**Sheet failures** (the sheet stays open, typed data kept): `IN001` → inline "No hay suficiente stock para ese ajuste. Actualiza la lista y revisa la cantidad."; offline → inline "Sin conexión. El ajuste no se guardó. Inténtalo de nuevo cuando tengas señal."; `IN002` → inline "Ese producto ya no está disponible." and "Aplicar ajuste" disabled; LP004 → `LimitePlanSheet` over the form; anything else → inline "No pudimos completar la operación. Intenta de nuevo."

**Success:** sheet closes, then the snackbar of §2.2 (with Deshacer only when |delta| ≤ 10).

### 4. ProductoFormScreen — create (`/inventario/nuevo`) and edit (`/inventario/:id/editar`)

`AppTopBar(title: 'Nuevo producto')` / `'Editar producto'`. Single scroll, 16px page padding, 16px between fields, primary button pinned at the bottom (safe area, rises with the keyboard). Reached only after the `asegurarEscritura` pre-check; if LP004 arrives from the server while saving, `LimitePlanSheet` opens and the typed data is kept.

**Create — one step (D-10), in this order:**

1. **"Nombre del producto"** — `AppTextField`, `autofocus`, `textCapitalization: sentences`, `maxLength: 80`, keyboard action "next". Validation: "Escribe el nombre del producto." Duplicate (server `23505`): inline under the field "Ya tienes un producto con ese nombre."
2. **"Unidad de conteo"** — Label then `Wrap` of single-select `AppFilterChip`: **Unidad · Tableta · Frasco · ml · Dosis · Caja · kg** (D-03). **"Unidad" preselected** so the fastest path needs no tap here. Helper Label `textMuted` "Cuentas siempre en esta unidad. No se puede cambiar después."
3. **"Cantidad inicial"** — numeric, `digitsOnly`, `maxLength: 7`, hint "0". Required, 0 allowed. Errors: "Escribe la cantidad (puede ser 0)." / "La cantidad máxima es 1.000.000."
4. **"Stock mínimo"** — numeric, `digitsOnly`, **prefilled "2"**, keyboard action "done". Helper "Te avisamos cuando queden menos de esta cantidad." Errors: "Escribe el mínimo (puede ser 0)."
5. **"Agregar más detalles"** — `Icons.expand_more` disclosure, collapsed by default (same pattern as 5.1), ≤ 200 ms animation. Inside:
   - **"Categoría"** — single-select `AppFilterChip`s: **Medicamento · Insumo · Alimento · Otro** (default Medicamento).
   - **"Vencimiento (opcional)"** — date field with calendar icon, hint "dd/mm/aaaa", `parsearFecha`; helper "Un solo vencimiento por producto." Past dates are allowed (the row will show "Vencido"). Error: "Escribe una fecha válida (dd/mm/aaaa)."
   - **"Precio de venta (opcional)"** — numeric, prefix "$", helper "En pesos, sin decimales." Digits only while typing, grouped with dots on blur (`$ 85.000` after `formatearCop`).
   - **"Costo (opcional)"** — same behaviour.
   - Footer Label `textMuted`: "Este inventario es de control interno de tu clínica." (kept to a single neutral sentence; makes no regulatory claim; planner may drop it.)
   - Price/cost errors: "Usa pesos enteros, sin coma." / "El valor es demasiado alto."
6. **Actions:** primary accent **"Guardar producto"** (`isLoading` during the request) and, under it, outline **"Guardar y agregar otro"** (keeps unidad and categoría, clears the rest, focus returns to Nombre — meant for loading the initial stock one-handed; planner may cut it without touching the contract). Both save through `crear_producto`.
7. **Success:** "Guardar producto" pops to the list with snackbar "«{nombre}» agregado al inventario."; "Guardar y agregar otro" stays with snackbar "«{nombre}» agregado. Puedes seguir con el siguiente."

**Edit (`/inventario/:id/editar`, same screen in edit mode):**
- Visible to every vet in the clinic (name, category, expiry are free for any vet per RESEARCH A1). "Más detalles" starts **expanded**.
- Fields: Nombre, Categoría, Vencimiento (editable by any vet); **Stock mínimo, Precio de venta, Costo** are editable **only for the admin**. For non-admins they render as read-only value rows (Label key + Body value, `surfaceMuted` fill, no lock icon) with the helper Label `textMuted` "Solo el administrador puede cambiar el mínimo y los precios."
- **Unidad** is shown as a read-only row (Label "Unidad de conteo", Body value) with helper "No se puede cambiar." **Cantidad is not editable here**; a Label `textMuted` line states "Para cambiar la cantidad usa Ajustar stock en el detalle."
- Primary **"Guardar cambios"**; success pops to the detail with snackbar "Cambios guardados."
- Server `42501` → snackbar "Solo el administrador de la clínica puede hacer esto." and the form stays.

### 5. ProductoDetailScreen (`/inventario/:id`)

`AppTopBar(title: 'Producto', actions: [edit icon])`. The edit action is `Icons.edit_outlined` (48dp, semantics "Editar producto"); in read-only (plan) it becomes `Icons.lock_outline` and opens `LimitePlanSheet`. Single scroll, 16px page padding, 24px between sections, bottom `xl` + safe area. Top to bottom:

1. **Header card** (`AppCard`, 16px padding):

## Accessibility & Interaction Notes

- **One-handed reach:** the FAB, the row buttons (right edge) and the sheet's primary button all sit in the lower two thirds; the search field is the only control in the top area besides the back arrow.
- **Targets:** every interactive element >= 48dp: row buttons (48×48), chips, steppers, FAB (56), snackbar action, "Ver bajos", dialog buttons, edit icon, disclosure header, Más row and Inicio card (56).
- **Status never color-only:** badges carry icon + text; movement direction carries sign + arrow; the "Agotado / Vencido" solid red badges also carry their words; quantities are numeric.
- **Contrast:** `primaryText` `#643312` on `warningBg` and on `surfaceMuted` >= 7:1 (as in 4.1 / 5 / 5.1); `onDestructive` on `destructive` as in Phase 5 "Vencida"; icons on `warningBg` use `primaryText`, with the `warning` hue limited to the badge border.
- **Semantics:** row = one node ("{nombre}, {n} {unidad}, mínimo {m}, {badges}. Abrir detalle") with the two buttons exposed as separate actions ("Descontar 1 de {nombre}", "Agregar stock a {nombre}"); locked controls "…, bloqueado, solo lectura"; filter chips announce selected state; sheet announced with its title and focus lands on the numeric field; after an adjustment the snackbar text is read as a live region.
- **Text scale 200 %:** badges wrap under the name block; row buttons keep 48×48 and stay at the end of row B; sheet and form scroll with the primary button pinned; quantity shrinks with `FittedBox`, never clips.
- **Keyboard:** numeric keypad on every quantity / price field; "next" from name to quantity to minimum, "done" on the last field; the sheet field autofocuses with its content selected; digits only (no decimals possible).
- **Double taps:** a row ignores further taps on its buttons while a request is in flight; the sheet and form ignore taps on the primary button while `isLoading`.
- **Animations <= 200 ms** (disclosure, sheet, chip selection); respect reduce-motion; no animated counters.
- **Refresh:** list, resumen and the product history are invalidated after every mutation; Inicio card and Más pill refresh through the same invalidation (RESEARCH G4); pull-to-refresh on the list.
- **Offline:** no queue (D-12); every failed write keeps the user's input and says it was not saved.
- **Dark mode:** follows the provisional dark tokens; the stock state map must be re-derived in Phase 8.
- **Regulatory:** the UI never presents the inventory as the official controlled-medication book; no control-especial label or warning exists in this phase.
