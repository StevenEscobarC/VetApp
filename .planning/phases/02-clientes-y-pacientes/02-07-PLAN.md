## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| ficha form -> clientes UPDATE | Vet-edited free text |
| app -> generar_codigo_vinculacion | Vet requests a secret the owner will later use to claim pets |
| screen -> clipboard | Code leaves the app via the OS clipboard |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-02-VINC | Spoofing / Information Disclosure | link code | mitigate | Code generated server-side (strong randomness, 24 h expiry, reused while valid, format-checked) via RLS-scoped security-invoker RPC; the app never chooses the code or writes the code columns directly |
| T-02-29 | Tampering | actualizar payload | mitigate | Payload whitelists nombre/telefono/email/direccion/notas only (no clinica_id, perfiles_id or code columns); RLS update policy is the boundary |
| T-02-30 | Information Disclosure | code copied to clipboard | accept | Vet explicitly taps 'Copiar código' to share in person; code expires in 24 h and is single-use once Phase 9 claims it |
| T-02-31 | Elevation of Privilege | claim flow | mitigate | Not implemented this phase (DIR-06, Phase 9); grep gate asserts no reclamar_codigo_cliente call |
</threat_model>
