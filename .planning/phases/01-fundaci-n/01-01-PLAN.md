| vet session -> clientes/mascotas rows | Vet chooses clinica_id / dueno_id values in inserts |
| SQL Editor (postgres role) -> smoke test | Privileged session; must leave no residue |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-01-RLS | Elevation of Privilege | perfiles_update policy | mitigate | WITH CHECK pins `rol` and `clinica_id` to the pre-update row via subqueries (Task 1 step 6); proven by smoke checks C5, C6, A17 |

| T-01-03 | Tampering | clientes/mascotas INSERT/UPDATE/DELETE across clinics | mitigate | WITH CHECK on clinica_id for insert/update, USING for update/delete; checks A7-A10, A13-A14, C8 |
| T-01-04 | Tampering | mascotas.dueno_id pointing at another clinic's cliente (FK bypasses RLS) | mitigate | Composite FK (dueno_id, clinica_id) -> clientes(id, clinica_id); check A15 |
