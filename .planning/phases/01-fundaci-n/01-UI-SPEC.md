# Phase 1 — UI Design Contract

> Visual and interaction contract for frontend phases. Generated by gsd-ui-researcher, verified by gsd-ui-checker.

---

## Scope

This is a **Walking Skeleton** phase (01-CONTEXT.md D-01/D-02). The UI surface is deliberately narrow:

**In scope:**
- **Login screen** (`lib/features/auth/presentation/screens/login_screen.dart`, split out of `auth_screens.dart` per 01-RESEARCH.md) — already functionally built, needs **visual restyle only** to match the terracota/crema tokens below. Copy is already final Spanish copy (see Copywriting Contract).
- **Inicio screen** (`lib/features/home/presentation/screens/inicio_screen.dart`, new) — a **minimal real dashboard**: greeting with the authenticated vet's real `nombre` and `clinicaNombre`, fetched via `authProfileProvider`, rendered with the approved palette/typography. No metrics cards, no "próximas citas", no "accesos rápidos" — those are Phase 8 (DASH-01..04).
- **Design tokens** (`app_colors.dart`, `app_typography.dart`) — corrected in place to match `.planning/design/DESIGN-REFERENCE.md`. This is a prerequisite fix, not a new screen, but it changes the rendered look of every existing widget (`AppButton`, `AppCard`, `AppTextField`, `AppStatusChip`, `AppTopBar`) app-wide.
- **Register / reset-password screens** — copy already exists and is unchanged; they inherit the corrected tokens automatically (no separate copy decisions needed here).

**Out of scope (belongs to later phases' own UI-SPEC):**
- Pacientes, Agenda, Clientes, Más — routed this phase only as `_ComingSoonScreen` placeholders (no design contract needed for a one-line "Próximamente" screen).
- Dashboard metrics cards, próximas citas, accesos rápidos — Phase 8.
- Any patient/client/appointment/invoice screen content — Phases 2–7.

## Spacing Scale

Existing `AppSpacing` tokens (`lib/core/theme/app_spacing.dart`) already match the 8-point scale and are reused as-is — no new tokens needed this phase:

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon-to-label gaps, inline padding |
| sm | 8px | Compact element spacing (form field internal gaps) |
| md | 16px | Default element spacing (screen padding, card padding) |
| lg | 24px | Section padding (Login card padding, Inicio card padding) |
| xl | 32px | Layout gaps (space above/below the Login logo block) |
| 2xl | 48px | Major section breaks (not used by Login/Inicio — reserved for later phases) |
| 3xl | 64px | Not currently defined in `AppSpacing`; not needed this phase (single-screen forms, no page-level rhythm this deep) |

Exceptions: `AppSpacing.touchTarget = 44px` (already defined) — every tappable bottom-nav icon and the Login "Olvidé mi contraseña" / "Crear cuenta" text links must hit a minimum 44×44px tap area even where the visual icon/text is smaller.

## Typography

| Role | Size | Weight | Line Height |
|------|------|--------|-------------|
| Body | 16px | 400 (regular, Figtree) | 1.5 |
| Label | 14px | 600 (semibold, Figtree) | 1.5 |
| Heading | 20px | 400 (Caprasimo — single weight) | 1.2 |
| Display | 28px | 400 (Caprasimo — single weight) | 1.2 |

**Usage mapping for this phase's screens:**
- Display (28px Caprasimo): "VetApp" brand title on the Login screen.
- Heading (20px Caprasimo): "Bienvenido a VetApp" Login subtitle-header, "Hola, {nombre}" greeting on Inicio, `AppTopBar` screen titles ("Inicio").
- Body (16px Figtree/400): form field text, input values, tagline ("Tu consultorio veterinario en el bolsillo"), clinic name on Inicio.
- Label (14px Figtree/600): button labels ("Iniciar sesión", "Crear cuenta"), input field labels ("Correo electrónico", "Contraseña"), bottom-nav item labels.

Only 2 distinct font weights are used across this phase: 400 and 600. Caprasimo ships one weight only (400) — do not attempt to bold it.

**Focal point per screen:** Login — the "VetApp" Caprasimo display title + logo mark, immediately above the primary "Iniciar sesión" button, is the primary visual anchor. Inicio — the "Hola, {nombre}" Caprasimo heading card is the primary visual anchor; everything else on the screen is secondary to it.

## Color

|------|-------|-------|
| Dominant (60%) | `#F5EAD8` (crema `background`) | Screen background on Login and Inicio |

| Accent (10%) | `#C67139` (terracota `primary`) | Reserved for: primary CTA button fill ("Iniciar sesión", "Crear cuenta", "Enviar enlace"), active bottom-nav icon + label, "Olvidé mi contraseña" / "Crear cuenta" link text, focus/ring state on the currently-edited input border |

Accent is never applied to: card backgrounds, body text, disabled states, or more than one primary CTA per screen.

## Copywriting Contract

|---------|------|
