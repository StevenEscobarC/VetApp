## Sampling Rate

- **After every task commit:** Run quick command on touched tests
- **After every plan wave:** Run `flutter analyze && flutter test`
- **Before `/gsd-verify-work`:** Full suite green + `RLS SMOKE: PASS` on live project + UAT `vetapp-qa` with 2 accounts (admin + invitado)
- **Max feedback latency:** 120 seconds
