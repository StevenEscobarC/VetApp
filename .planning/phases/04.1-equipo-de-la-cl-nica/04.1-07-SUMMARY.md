# Phase 4.1 Plan 07: Gestionar el equipo Summary

Admins can promote/demote, retire (with open-cita reassignment) and leave the clinic from Más > Equipo, using the live `retirar_miembro` / `cambiar_rol_miembro` RPCs with Spanish error mapping.

## Commits
- 4b9dd18: repository + TeamActions (retiro, rol, conteo de citas abiertas)
- 051d0be: member actions sheet, reasignar sheet, Equipo wiring, tests

## What was built
- Repository: `contarCitasAbiertas`, `retirarMiembro` (params always sent, `p_reasignar_a` nullable), `cambiarRol`; `_messageFor` maps last-admin, "ya no está en tu clínica" and 42501.
- TeamActions invalidates teamProvider and agendaSemanaProvider, increments citasRevisionProvider, and invalidates authProfileProvider when acting on oneself.
- Tiles are tappable only for admins on active members; own tile shows leave/demote only when another admin exists, otherwise the explanatory text.
- Retiro flow: count -> destructive confirm -> reasignar sheet only when open citas exist and a vet other than the admin is available; otherwise null (server assigns to the admin).

## Deviations from Plan
- Pluralization: sheet text uses "3 citas próximas" / "1 cita próxima" instead of the literal "cita(s)".
- No spinner on confirm buttons (dialogs close immediately, result shown by snackbar); minor UX gap versus the behavior bullet.
- Test fixtures use the existing names (Luis Gómez) rather than "Luis Torres".
