<objective>
First vertical slice. The vet opens Más > Cobros and sees the clinic's summary, both document lists with their state, and the read-only detail of any document. It also adds the shared billing display widgets (state chip, toggle, "Cobrar" button and "Cobrada" row) that later slices reuse, and the base top-level routes.

## Phase Goal

**As a** veterinario independiente o de una clínica pequeña, **I want to** cobrar mis consultas, servicios y productos con una cotización o una cuenta de cobro en PDF que comparto por WhatsApp, **so that** el cliente sepa cuánto debe, yo sepa qué está pagado y el inventario se descuente solo.

Output: Más row, Cobros screen, detail screen (read), 5 widgets, routes and 4 test files. Built on FakeCobrosRepository; live data arrives with 07-08.
</objective>
