- `clave_idempotencia.dart`: `String generarClaveIdempotencia([Random? rng])`:
  - 16 bytes from `rng ?? Random.secure()`;
  - byte 6 = (b & 0x0f) | 0x40;
  - byte 8 = (b & 0x3f) | 0x80;
  - lowercase hex in the 8-4-4-4-12 layout.

- `whatsapp_cobro.dart`: `String mensajeCobroWhatsApp({required String cliente, required String numero, required int totalCop, required String clinica, required String veterinario, String? mascota, required bool esCotizacion, bool pagada = false, DateTime? validaHasta})`.
  - The firma is `firmaVeterinario(veterinario)` plus `', $clinica'` when the clinic is non-blank (the clinic alone when the vet name is blank).
  - Templates (UI-SPEC §4.3, verbatim):
    - CC pending: 'Hola, {cliente}. Le compartimos la cuenta de cobro {numero} de {clinica} por {formatearCop(total)}{, por la atención de {mascota}}. Quedamos atentos a su pago. — {firma}'
    - CC paid: 'Hola, {cliente}. Le compartimos la cuenta de cobro {numero} de {clinica} por {formatearCop(total)}, ya pagada. Gracias por su confianza. — {firma}'
    - quote: 'Hola, {cliente}. Le compartimos la cotización {numero} de {clinica} por {formatearCop(total)}{, para {mascota}}. Es válida hasta el {formatearFecha(validaHasta)}. — {firma}'
- `formato.dart` additions:
  - `({String? valor, String? error}) normalizarCedula(String texto)`:
    - strip dots and spaces;
    - empty → (valor: null, error: null);
    - `^[0-9]{5,12}$` → (valor: digits, error: null);
    - else → error 'Revisa la cédula: debe tener entre 5 y 12 números.'
  - `String formatearCedula(String digitos)` → '1.020.304.050' (dots every 3 from the right; non-digit input returned unchanged).
  - `({String? valor, String? error}) normalizarNit(String texto)`:
    - strip dots and spaces;
    - empty → (null, null);
    - `^[0-9]{5,12}(-[0-9])?$` → valor;
    - else → error 'Usa solo números y, si es NIT, el guion del dígito de verificación.'
  - `String formatearNit(String nit)` → '900.123.456-7' (groups the digit part, keeps '-d').
