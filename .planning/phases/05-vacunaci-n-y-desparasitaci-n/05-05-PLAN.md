**As a** veterinario, **I want to** registrar una vacuna o desparasitación con dos toques y ver de inmediato la próxima fecha calculada, **so that** no escriba fechas a mano y el carné quede al día.

Purpose: one top-level route outside the bottom-nav shell so every entry point pushes the same screen without cross-branch navigation; callers receive a `DosisRegistrada` result and show the confirmation snackbar.
Output: route, providers, screen, 4 widgets, widget test.
