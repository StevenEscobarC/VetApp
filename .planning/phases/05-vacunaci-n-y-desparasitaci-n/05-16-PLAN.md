## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-05-51 | Information Disclosure | Edge Function signing arbitrary paths | mitigate | Only paths matching LOGO_RE (clinic uuid + logo-<digits>.jpg) are signed, and only the path returned by carne_publico for the token's clinic; logo_path is deleted from the response |
| T-05-52 | Information Disclosure | long-lived logo URL leaking | mitigate | 300 s signed URL, private bucket, referrerpolicy no-referrer, cache-control no-store on the JSON |
