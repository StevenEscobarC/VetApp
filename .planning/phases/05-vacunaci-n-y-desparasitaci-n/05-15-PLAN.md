## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-05-46 | Denial of Service | huge or malformed images | mitigate | capturador compresses to 1024 px; recortarCuadradoPng re-encodes to a 512 px square (drops metadata, decodes untrusted formats via dart:ui only); kMaxBytesLogo guard before upload; bucket limit 1 MB server-side (05-14) |
| T-05-47 | Elevation of Privilege | non-admin reaching edit UI | mitigate | UI gating via puedeEditarClinicaProvider; server is authoritative (actualizar_clinica + storage policies admin-only, 05-14); 42501 mapped to Spanish message |
| T-05-48 | Tampering | path traversal from client | mitigate | Path is built only by ClinicaLogoDatasource.rutaLogo from the profile clinicaId + epoch; server regex rejects anything else |
| T-05-49 | Information Disclosure | EXIF/GPS metadata inside the logo photo | mitigate | Re-encoding through dart:ui canvas + JPEG compression produces a new image without EXIF |
| T-05-50 | Repudiation / storage leak | orphan objects after failed saves | mitigate | GuardarDatosClinica deletes the new upload when the RPC fails and the old logo after success (best effort) |
</threat_model>
