Edge Function response (the page's contract):
- 200 `application/json; charset=utf-8`, `cache-control: no-store`: the carne_publico JSON with `mascota.foto_path` REMOVED and `mascota.foto_url` (signed URL, 300 s) or null.
- 404 `{"error":"no_encontrado"}` for malformed token, unknown/regenerated token, or any upstream failure that is a "not found"; 500 `{"error":"interno"}` only for unexpected failures; 405 for methods other than POST/OPTIONS.
- Request: `POST` body `{"token": "<64 hex>"}`; CORS `Access-Control-Allow-Origin` = env `CARNE_ORIGEN` (default 'https://stevenescobarc.github.io'), `Vary: Origin`, preflight allows `POST` and header `content-type`.
- Runtime env provided by Supabase: SUPABASE_URL, SUPABASE_SERVICE_ROLE_KEY (never in repo, never in the page).

Page config: `public_carne/c/config.js` is NOT committed; the workflow generates it as `window.CARNE_CONFIG = { functionUrl: "<vars.CARNE_FUNCTION_URL>" };`. Shared link format (05-06 `kCarneBaseUrl`): `https://stevenescobarc.github.io/VetApp/c/#<token>`.

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Internet (anyone with or without a token) -> Edge Function | Fully untrusted input; the only anonymous entry point |
| Edge Function -> PostgREST/Storage with service role | Highest privilege key in the system |
| Database strings (clinic, producto, lote, names) -> owner's browser | Stored content authored by vets rendered on a public page |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-05-13 | Information Disclosure | token enumeration | mitigate | 244-bit token; regex check before DB; identical 404 for malformed/unknown/regenerated |
| T-05-14 | Information Disclosure | token leakage | mitigate | Token in `#` fragment + POST body; `referrer: no-referrer` meta and fetch referrerPolicy; noindex; no query string |
| T-05-15 | Elevation of Privilege | service role key | mitigate | Only `Deno.env` in the function; grep gates for JWT literals; page/workflow have no secrets |
| T-05-16 | Tampering (XSS) | page rendering | mitigate | textContent only (grep gate), meta CSP `default-src 'none'`, script-src 'self', img only from supabase.co |
| T-05-17 | Information Disclosure | CORS | mitigate | Allow-Origin fixed to the Pages origin, never `*` |
| T-05-18 | Information Disclosure | photo / private bucket | mitigate | Signed URL TTL 300 s, foto_path stripped, degrade without photo |
