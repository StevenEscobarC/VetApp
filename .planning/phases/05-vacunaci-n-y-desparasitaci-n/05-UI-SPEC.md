# Phase 5 — UI Design Contract

> Visual and interaction contract. Generated by gsd-ui-researcher, verified by gsd-ui-checker.

---

## Scope

**Tokens LOCKED from Phases 1-4.1** (`lib/core/theme/*`). This phase redefines no font, spacing or core color token. Additions are limited to: (a) a **dose-status style map** built from existing colors (see Color), (b) one **public web surface** (carné) that re-implements the same tokens in HTML/CSS, and (c) a PDF layout.

**Decisions consumed (not re-asked):** D-00..D-19 from `05-CONTEXT.md`; protocol/chip data from `05-PROTOCOLOS-RESEARCH.md`; tokens, 48dp targets, `AppButtonVariant.destructive`, `VetAvatar`, one-accent-CTA-per-screen rule, Deshacer snackbar, tone and `Atendió:` attribution from `04.1-UI-SPEC.md` / `04-UI-SPEC.md`; mockup screen 7 "Carné de vacunación" (cards per vaccine: name, applied/next date, state Al día/Próxima, "Compartir carné").

**Guiding rule (D-00, zero friction):** Registering a dose = tap biológico, confirm date (prefilled today), tap Guardar. Never a typed date, never more than 2 required inputs. "Próxima" is always shown computed, never editable (Pitfall 7).

**In scope (surfaces):**
1. Carné section in `MascotaDetailScreen` (dose cards, "+ Registrar dosis", "Compartir carné").
2. `RegistrarDosisScreen` (full-screen form) + "Otro" biológico + external dose.
3. Anular dosis (bottom sheet with motivo).
4. "Vacunar" quick action (Inicio) + mascota search sheet.
5. Completar cita -> "Registrar dosis" entry.
6. Inicio card "Vacunas pendientes".
7. `VacunasPendientesScreen` (Vencidas / Próximas) with row actions, Descartar/posponer sheet.
8. Badges in pacientes list and ficha.
9. Más > Protocolos (`ProtocolosScreen`, edit sheet, "Nuevo biológico").
10. "Compartir carné" bottom sheet (WhatsApp, native share, PDF, Regenerar link).
11. PUBLIC carné web page (valid, invalid/revoked, loading states).
12. Carné PDF layout.

**Out of scope (render nothing):** push/local notifications, QR code, "¿Puede ir a guardería?" semáforo, automatic reminders, inventory deduction, vaccines section inside consulta form, owner login.

| lg | 24px | Gap between biológico groups, between form sections, public page section gaps |

## Typography

Same 4 roles, same 2 weights. **No new sizes or weights**, app and public page alike.

| Role | Size | Weight | Line Height |
|------|------|--------|-------------|
| Body | 16px | 400 (Figtree) | 1.5 |
| Label | 14px | 600 (Figtree) | 1.5 |
| Heading | 20px | 400 (Caprasimo) | 1.2 |
| Display | 28px | 400 (Caprasimo) | 1.2 |

**Usage mapping:**
- **Display (28px):** the pet name on the public carné and PDF header only. The title "Carné de vacunación" is Heading.
- **Heading (20px):** `AppTopBar` titles ("Vacunas pendientes", "Registrar dosis", "Protocolos"), biológico group header in carné ("Polivalente"), sheet titles, "Vencidas"/"Próximas" group headings, public page section headings, invalid-link heading.
- **Body (16px):** dose dates, product/lote values, field values, owner-facing copy on public page, dialog bodies, `Próxima: dd/mm/aaaa` preview.
- **Label (14px/600):** status chips, "Dosis 2 de 3" / "Refuerzo" tag, "Aplicó: Dr(a). X", "Otra clínica" tag, duration chip text, field labels, helper/error text, badge text, group counts, "Hecho con VetApp" footer.

**Focal points:** Carné: the first non-up-to-date dose card (Vencida/Próxima) sorts first, then Al día. Registrar dosis: the biológico picker, then the `ProximaPreview`. Pendientes: the "Vencidas" group heading. Compartir sheet: "Enviar por WhatsApp". Public page: pet name (Display).

## Color

60/30/10 reused verbatim.

| Role | Value | Usage this phase |
|------|-------|------------------|
| Dominant (60%) | `#F5EAD8` `background` | All new screens, public page body |
| Secondary (30%) | `#EEE7DB` `surface`, `#DCD3C4` `border`, `#EBDDC5` `surfaceMuted` | Dose cards, pending tiles, sheets, public certificate card (`surface`), chips inactive |
| Accent (10%) | `#C67139` `primary` | See reserved list |
| Destructive | `#DC2626` | "Anular dosis" label/confirm, "Regenerar link" confirm, "Vencida" chip fill, error text |

**Accent reserved for (and only):**
1. "+ Registrar dosis" primary on the Carné section (that screen's one accent CTA; "Compartir carné" is **outline**).
2. "Guardar dosis" primary on `RegistrarDosisScreen`.
3. "Vacunar" quick-action tile icon/label emphasis on Inicio (the existing quick-action styling; no extra CTA).
4. "Enviar por WhatsApp" is **outline** in the share sheet (the sheet's one accent is none: sheet actions are all outline to avoid a CTA fight; WhatsApp row gets the existing WhatsApp-icon treatment).
5. "Nuevo biológico" primary on Protocolos (the screen's one accent CTA).
6. Selected `DuracionChips` / `AppFilterChip.selected` state (Vencidas | Próximas | Todas filter, species filter), focus ring on edited field, active bottom-nav item.
7. Public page: no accent CTA; terracota only for the header rule (2px) and the pet-name underline accent. Nothing on the public page is a button except none (read-only).

Accent is never used for: status chips, dose cards, badges, "Aplicó" attribution, group headings, or more than one primary CTA per screen.

**Dose status style map (no new colors; color is never the sole cue — icon + text always present):**

| Estado | Chip fill | Text/icon | Icon | Label | Card stripe (4px left) |
|--------|-----------|-----------|------|-------|------------------------|
| Al día | `successBg` `#F0FAE1` | `success` `#56633F` | `check_circle_outline` | "Al día" | `success` |
| Próxima | `warningBg` `#FFF2EB` | `primaryText` `#643312` (icon `warning` `#D97706`) | `schedule` | "Próxima" | `warning` |
| Vencida | `destructive` `#DC2626` solid | `onDestructive` white (>= 4.8:1) | `error_outline` | "Vencida" | `destructive` |
| Anulada | `surfaceMuted` | `textMuted` `#645C50`, dose text strikethrough | `block` | "Anulada" | `border` |
| Externa | `surfaceMuted` | `textSecondary` `#474238` | `apartment_outlined` | "Otra clínica" | none (tag, not a state; combines with Al día/Próxima/Vencida chips as a second tag) |

"Externa" is shown as an additional tag next to the state chip, not as a replacement, so a dose applied elsewhere still shows its validity.

**Public page and PDF** use the same hex values. PDF is print-safe: status shown by text + icon glyph + chip border, fills lightened (no solid red block): Vencida in PDF = 1px `destructive` border with `destructive` text.

## Layout & Component Patterns

### 1. Carné section (MascotaDetailScreen)
Placement: a "Carné" tab/section in the ficha (D-05a), after historial. Heading "Carné de vacunación" (Heading) with trailing Label count "{n} dosis".

Top to bottom:
1. **Summary strip** (only when >= 1 active dose): `AppCard` `surfaceMuted`, one row, Label: overall `DosisEstadoChip` of the worst state among the pet's biológicos ("Vencida" > "Próxima" > "Al día") + Label `textSecondary` "{n} pendientes" if any. Hidden when no doses.
2. **Biológico groups** sorted by urgency (Vencida, Próxima, Al día), then alphabetically. Each group: `BiologicoGroupHeader` = leading icon (vaccines/medication/bug) + Heading biológico name ("Antirrábica") + trailing `DosisEstadoChip` for the group's current state. Under it, the **current dose card** (`DosisCard`, full details) and a collapsed disclosure "Historial ({n})" (chevron, same pattern as "Agregar más detalles") listing earlier doses as compact rows.
3. **`DosisCard`** (`AppCard`, 4px status stripe left, 16px padding, min 48dp tappable to expand):
   - Row 1: Label (14px/600): "Dosis 2 de 3" or "Refuerzo" (tag, `surfaceMuted` pill) + trailing state chip (+ "Otra clínica" tag if externa).
   - Row 2 (Body): "Aplicada: 14/09/2026".
   - Row 3 (Body): "Próxima: 05/10/2026" (Al día/Próxima/Vencida; for a series' final dose with no booster: "Sin refuerzo"). Vencida shows Label `destructive` "Venció hace 12 días".
   - Row 4 (Label `textSecondary`): "Producto: Nobivac · Lote: A123" (omitted if empty).
   - Row 5 (Label `textSecondary`): "Aplicó: Dr(a). Laura Gómez · Mat. 12345" with `VetAvatar` 24 leading, **always shown in the carné** (unlike timeline: it is a certificate; per 4.1 rules the matrícula appears in documents). Retired vet: "(retirado)" suffix in `textMuted`. Externa: "Aplicada en {Clínica externa}" instead, or "Aplicada en otra clínica" if no name.
   - Trailing overflow `Icons.more_vert` (48dp, semantics "Más acciones") with a single action "Anular dosis" (destructive label) — only for non-anulada doses.
   - **Anulada**: whole card at `textMuted`, date/product text strikethrough, extra Label line "Anulada: {motivo}" and "{dd/mm/aaaa}". No actions. Appears only in Historial, never as the current dose.
4. **Empty state** (no doses): see Copy. Illustration is `Icons.vaccines_outlined` 32px in a 64px `surfaceMuted` circle (local constant).
5. **Pinned bottom actions** (same pattern as Agenda "Nueva cita"): primary accent **"+ Registrar dosis"** (`Icons.add`) and, above it row-wise, outline **"Compartir carné"** (`Icons.share_outlined`, disabled with helper if no active doses: tap shows snackbar "Registra al menos una dosis para compartir el carné"). Layout: two buttons stacked, 8px gap, 48dp each.

### 2. RegistrarDosisScreen
`AppTopBar(title: 'Registrar dosis')`, subtitle Label `textSecondary` with pet name + `VetAvatar`-style pet photo 24px. Single scroll form, `md` gaps. Order (D-06, minimum first):
1. **Biológico** (required): tappable `AppCard` row (48dp+), Label "Biológico", value Body or hint "Elige un biológico", trailing `keyboard_arrow_down`. Opens a bottom sheet "Biológico" with instant-search field at top (`AppTextField`, autofocus, hint "Buscar biológico") and list (56dp rows): species-filtered catalog (e.g. Perro: Puppy DP, Polivalente, Leptospirosis, Bordetella, Antirrábica, Desparasitación interna, Desparasitación externa), each row with icon, name, and Label `textSecondary` hint **"Dosis 2 de 3"/"Refuerzo"/"Primera dosis"** inferred from history (D-02). Last row: **"Otro..."** (`Icons.add`). Preselected when entered from an alert (D-12) or from a dose card of that group.
2. **Fecha** (required): `AppTextField`-style tappable row, Label "Fecha de aplicación", value "Hoy · 01/10/2026" (dd/mm/aaaa) prefilled; tap opens date picker (limited to <= today; no future dates). Helper `textMuted` appears if date < today: "Fecha pasada: se registrará como dosis histórica."
3. **`DuracionChips`** (shown only when the biológico has `opciones_duracion` per D-03, e.g. antirrábica, desparasitante externo): Label "Duración del producto", wrapped row of 48dp `AppFilterChip`s, single-select, protocol default preselected: antirrábica "1 año" (default) / "3 años"; externo "1 mes" / "5 semanas" / "3 meses". Hidden for biológicos without options (no empty control).
4. **`ProximaPreview`** (live, read-only, updates on any change of biológico/fecha/duración): `AppCard` `surfaceMuted`, `Icons.event_outlined` + Body "Próxima: 05/10/2026" and Label `textSecondary` the context line "Dosis 2 de 3 · en 21 días" or "Refuerzo anual" or "Serie completa. Sin más dosis hasta el refuerzo." No edit affordance; Label `textMuted` "Se calcula sola con el protocolo." Before a biológico is chosen the card is not rendered. If a serie gap warning applies (research §3.6): `warningBg` row, Label "Pasó mucho tiempo desde la dosis anterior. Puede reiniciar la serie." with text button "Reiniciar serie" (suggestion only, never blocks save).
5. **Switch "Aplicada en otra clínica"** (D-07): `SwitchListTile`-style row 56dp. When on: reveals `AppTextField` "Nombre de la clínica (opcional)"; hides "Aplicó" attribution line in preview; Label helper `textMuted` "Se mostrará diferenciada en el carné."
6. **"Agregar más detalles"** disclosure (collapsed by default, existing pattern): `AppTextField` "Producto / marca" (autocomplete: overlay list of the clinic's last 5 products, each row Body producto + Label `textSecondary` "Último lote: A123"; picking a row fills producto and lote), "Lote", "Observaciones" (multiline, 3 lines). All optional.
7. **Footer**: Label `textSecondary` "Aplicó: Dr(a). {Nombre}" with `VetAvatar` 24 (current vet; hidden when "otra clínica" is on). Primary accent **"Guardar dosis"** pinned at bottom, `isLoading` while saving. On success: pop, snackbar "Dosis registrada. Próxima: 05/10/2026" with action "Compartir carné" (opens the share sheet). No Deshacer: doses are append-only (correct via Anular).

**"Otro" biológico (D-04):** after choosing "Otro...", the biológico card is replaced by `AppTextField` "Nombre del biológico" (required, autofocus) and the `DuracionChips` become **"Intervalo de refuerzo"** with 6 chips: "21 días", "1 mes", "3 meses", "6 meses", "1 año", "Sin refuerzo" (default "1 año"). Below: switch **"Guardar en mi catálogo"** (default on) with helper "Aparecerá en Más > Protocolos." Everything else identical.

### 3. Anular dosis (D-08)
Opened from `DosisCard` overflow. Bottom sheet (non-full height): Heading "Anular dosis", Body "{Biológico} · {dd/mm/aaaa}". Field chips (single-select 48dp `AppFilterChip`s) "Motivo": "Error de registro", "Dosis duplicada", "Otro motivo"; "Otro motivo" reveals `AppTextField` "Describe el motivo" (required, max 120). Body `textSecondary`: "La dosis quedará tachada y no contará para la próxima fecha. No se puede deshacer." Actions: outline "Volver" / **destructive "Anular dosis"** (disabled until a motivo is picked). Success: snackbar "Dosis anulada. Registra la correcta." with action "Registrar dosis" (opens form with the biológico preselected).

### 4. "Vacunar" quick action + mascota search
- Inicio: existing quick-action row/grid gains **"Vacunar"** tile (`Icons.vaccines_outlined`, 48dp+ tile, same as other tiles). Tap opens full-height bottom sheet "¿A quién vacuna?": autofocus `AppTextField` search (hint "Buscar mascota o dueño", instant, same search as Phase 2), results 56dp rows (pet avatar 40 + Body nombre + Label `textSecondary` "{Especie} · {Dueño}"), each with trailing `DosisEstadoChip` of its worst state. Tapping a row opens `RegistrarDosisScreen` for that pet. Empty result: Body `textSecondary` "No encontramos esa mascota." + outline "Registrar paciente nuevo" (Phase 2 flow).
- Also exposed in Agenda via the same sheet if Agenda has a quick-action menu (reuse widget `MascotaSearchSheet`).

### 5. Completar cita -> registrar dosis (D-05b)
In `CompletarCitaScreen`, when the cita motivo is "Vacunación" or "Desparasitación": after the existing "Registrar consulta" offer, a second `AppCard` row (48dp+, `Icons.vaccines_outlined`) "Registrar dosis aplicada" with Label `textSecondary` "{Mascota}". Tap opens `RegistrarDosisScreen` preselecting biológico category (Vacunación -> picker opened; Desparasitación -> "Desparasitación interna" preselected, switchable). Completing the cita without registering is never blocked and no reminder snackbar is shown. Not shown for other motivos.

### 6. Inicio card "Vacunas pendientes" (D-10)
`AppCard` (same family as other Inicio summary cards), full width, tappable (48dp+), `Icons.vaccines_outlined` + Heading "Vacunas pendientes"; body Label rows: `DosisEstadoChip(vencida)` "{n} vencidas" and `DosisEstadoChip(proxima)` "{n} próximas"; chevron trailing. When 0/0: Body `textSecondary` "Todo al día" with `check_circle_outline` in `success`; card remains visible. Counts are clinic-wide (D-14). Loading: skeleton `surfaceMuted` card. Error: Label "No pudimos cargar las vacunas." inline + text "Reintentar".

### 7. VacunasPendientesScreen (D-10..D-14)
`AppTopBar(title: 'Vacunas pendientes')`. Under it: filter row (48dp `AppFilterChip`s): "Todas" (default) | "Perros" | "Gatos" (optional species filter; if cut, nothing else changes). Body scroll:
- **Group "Vencidas ({n})"** (Heading) then `PendienteTile`s sorted by days overdue desc.
- **Group "Próximas ({n})"** (Heading) sorted by due date asc.
- **`PendienteTile`** (`AppCard`, 16px padding): Row 1: pet avatar 40 + Body nombre + Label `textSecondary` "{Dueño}"; trailing `DosisEstadoChip`. Row 2: Body "{Biológico} · {Dosis 2 de 3 | Refuerzo}". Row 3: Label: Vencida -> `destructive` "Venció el 12/09/2026 · hace 19 días"; Próxima -> "Vence el 05/10/2026 · en 4 días". Row 4 (if sent): Label `textMuted` with `Icons.history` "Recordatorio enviado el 28/09/2026". Row 5 **actions**: a wrap of four 48dp controls: **"Recordar"** (outline, WhatsApp icon; opens WhatsApp with the message below, then sets "recordatorio enviado" on return/confirm), **"Agendar"** (outline, `Icons.event_outlined`; opens `CitaFormScreen` with cliente, mascota and motivo prefilled), **"Registrar"** (outline, `Icons.vaccines_outlined`; opens form with biológico preselected), **"Descartar o posponer"** (text, `Icons.snooze`; opens sheet). No accent button on this screen (4 outline actions per tile would be noisy: the tile itself is tappable and opens the ficha Carné).
- Layout of actions: icon+label 14px; if the owner has no phone: "Recordar" disabled with Label `textMuted` "Sin teléfono" under it (same pattern as Phase 4 `Sin registrar`).
- **Descartar/posponer sheet (D-12)**: Heading "¿Qué hacemos con esta alerta?", single-select rows (56dp): "Posponer 7 días" / "Posponer 30 días" / "Mascota fallecida" / "Cambió de veterinario" / "Otro motivo" (reveals `AppTextField` "Motivo", optional). Actions: outline "Volver" / primary-text "Aplicar". Posponer hides until date then re-enters lists. Descartar states mute the alert permanently (carné still shows the dose). Success snackbar "Alerta descartada" / "Alerta pospuesta hasta el {dd/mm/aaaa}" with Deshacer (this is reversible, allowed).
- **D-13:** items overdue > 6 months are not listed; footer Label `textMuted` (only if any hidden): "Se ocultan las vacunas vencidas hace más de 6 meses. Siguen marcadas en cada carné."
- **Empty (no alerts):** Heading "Todo al día", Body `textSecondary` "No hay vacunas vencidas ni próximas en la clínica."
- Not filtered per veterinarian (D-14). In multi-vet mode no vet marker is added to tiles (alerts belong to the clinic).

### 8. Badges in pacientes list and ficha
- **Pacientes list row:** trailing small `DosisEstadoChip` (compact variant: icon + label, 14px, 28px tall visual / 48dp row tap target unchanged) **only for Vencida and Próxima**; Al día shows nothing (reduce noise), no doses shows nothing. Worst state across the pet's biológicos wins.
- **Ficha header:** same chip under the pet name when Vencida/Próxima; tapping scrolls/switches to Carné. Al día shows `check_circle_outline` + "Vacunas al día" Label `success`. Never any accent color.

### 9. Más > Protocolos (D-01)
Entry in `MasScreen`: `AppCard` row, `Icons.tune`, label "Protocolos de vacunación", trailing chevron. Visible to all vets; **editing allowed to any vet of the clinic** (single-vet default) — in multi-vet, editing is admin-only and non-admins see read-only tiles without chevron plus Label `textMuted` "Solo los administradores pueden cambiar los protocolos."

`ProtocolosScreen`: `AppTopBar(title: 'Protocolos')`, species filter `AppFilterChip` row "Perros | Gatos" (default Perros), list of `ProtocoloTile` (`AppCard`): icon + Body biológico name + Label `textSecondary` summary "3 dosis cada 21 días · refuerzo anual" + trailing Label tag "Personalizado" (`surfaceMuted` pill) when overridden or custom. Tap opens **edit sheet** (full-height): Heading biológico; fields: "Dosis de la serie" (stepper 1-6, 48dp buttons), "Intervalo entre dosis" (chip set 14 días / 21 días / 28 días / 1 mes / 3 meses), "Refuerzo" (chips "6 meses", "1 año", "3 años", "Sin refuerzo"), "Duraciones disponibles al registrar" (multi-select chips), read-only Label "Edad mínima: 8 semanas" (not editable). Primary accent **"Guardar cambios"**; text "Restablecer valores estándar" (only if overridden; confirm dialog, non-destructive wording). Custom biológicos (created via "Otro" or here) also show text button **"Desactivar"** (destructive label, hides from picker, existing doses unaffected; confirm dialog). Seed biológicos cannot be removed, only reset.
- Screen's one accent CTA: **"Nuevo biológico"** pinned bottom (`Icons.add`): opens the same sheet with "Nombre", "Especie" chips (Perro / Gato / Ambos) and the fields above.
- Info banner `surfaceMuted` at top (not dismissible, Label `textSecondary`): "Los cambios aplican a las próximas dosis que registres. Las fechas próximas se recalculan con el nuevo protocolo." Copy: see Copywriting (próximas fechas se recalculan, since next dose is derived, Pitfall 7).

### 10. Compartir carné sheet (D-16, D-17)
Bottom sheet from "Compartir carné", Heading "Compartir carné de {Mascota}", under it Label `textSecondary` truncated link `vetapp.co/c/…x7Kq` (the final host is a technical decision; display shows the domain + last 4 chars). Rows (56dp, `AppCard`-like list tiles, icon + Body + chevron):
1. **"Enviar por WhatsApp al dueño"** (first, focal; label with "Dueño: {Nombre} · +57 3XX XXX XXXX" Label `textSecondary`). If owner phone missing: row disabled, Label `textMuted` "Sin teléfono registrado".
2. **"Compartir enlace"** (`Icons.share_outlined`, native share sheet with link + short formal message).
3. **"Descargar PDF"** (`Icons.picture_as_pdf_outlined`; generating spinner in row, then opens share/print via `printing`).
4. **"Copiar enlace"** (`content_copy_outlined`, snackbar "Enlace copiado").
5. Separator, then text row **"Regenerar enlace"** (`Icons.link_off_outlined`, `destructive` label) with Label `textSecondary` "El enlace anterior dejará de funcionar".
Regenerar confirm dialog: Title "¿Regenerar el enlace del carné?" Body "El enlace anterior dejará de funcionar. Quien lo tenga verá un aviso de enlace no válido. Deberá compartir el nuevo." Actions "Volver" / **"Regenerar"** (destructive). Success snackbar "Enlace regenerado".
First open: link is created lazily; sheet shows 20px spinner in the link line "Creando enlace..." and rows are disabled until ready. Error: "No pudimos crear el enlace. Intenta de nuevo." + text "Reintentar".

### 11. PUBLIC carné web page (D-15, D-16, D-18, D-19)
Static, mobile-first (375px baseline), **no app chrome** (no nav, no login, no download banner above the fold), `lang="es-CO"`, `<title>Carné de vacunación · {Mascota}</title>`, `noindex, nofollow`, no cookies, no third-party scripts apart from the font link. Background `#F5EAD8`; content max-width 640px, centered, 16px horizontal padding (24px >= 600px).

Structure (certificate style):
1. **Header band**: clinic name (Label) with clinic city if known, 2px `primary` rule below, Heading "Carné de vacunación".
2. **Pet block** (`surface` card, 1px `border`, radius `radiusLg`): pet photo 64px circle (initial letter fallback `surfaceMuted`) + **pet name in Display** + Label `textSecondary` "{Especie} · {Raza} · {Sexo}" and Body "Nació el 12/03/2025 · 1 año 6 meses" when known. No owner contact data; owner appears only as first name + initial of last name ("Propietario: Ana R.") — minimum per D-15.
3. **Summary chip row**: overall `DosisEstadoChip` + Label "Actualizado el 01/10/2026" (data freshness, Bogotá time).
4. **Doses grouped by biológico** (Heading per group, no collapsed UI; Historial included expanded below current): each dose = a certificate row card with fields as a definition list: **Fecha de aplicación**, **Producto**, **Lote**, **Vigente hasta / Próxima dosis**, **Estado** (chip), tag "Otra clínica" when externa, **"Aplicó: Dr(a). {Nombre} · Mat. {n}"** (omitted for externas). Anuladas are **hidden** on the public page (never shown to owners) — only valid doses appear. Labels 14/600 `textSecondary`, values 16/400 `foreground`.
5. **Clinic block** at bottom: clinic name, address, phone (clinic's, not owner's) — Label.
6. **Footer** (D-19): centered Label `textMuted`, 24px above bottom: "Hecho con VetApp" (plain text, not a link in v1 unless a landing exists; if a landing URL exists, link with underline, `primaryStrong`). One line only.
7. **Legal note** (Label `textMuted`, above footer): "Este carné es informativo. Para trámites de viaje o certificados oficiales, solicite el documento firmado a su veterinario." (does not cite regulation).

States:
- **Loading**: skeleton blocks `surfaceMuted` for header and pet block, no spinner library; if RPC takes > 3 s, Label "Cargando carné...".
- **Invalid/revoked/not found** (single state, do not reveal which): centered, 64px `surfaceMuted` circle with `link_off` glyph (inline SVG) in `textMuted`, Heading "Este enlace no es válido", Body `textSecondary` "Es posible que haya sido reemplazado. Pídale a su veterinario que le envíe el enlace actualizado.", footer "Hecho con VetApp". HTTP status 404 equivalent; no pet data.
- **Network error**: Heading "No pudimos cargar el carné", Body "Revise su conexión e intente de nuevo.", outline button "Reintentar" (48px, only interactive element on the page).
- **Pet with no valid doses**: Body "Esta mascota aún no tiene vacunas registradas."
- Accessibility: semantic `<h1>` pet name, `<h2>` per biológico, `<dl>` per dose, chips with text + icon, contrast >= 4.5:1, supports 200% zoom without horizontal scroll, `prefers-reduced-motion` respected (no animation anyway), print stylesheet hides nothing and keeps `surface` as white. Dark mode: not supported on the public page in v1 (single light palette), reconfirm in Phase 8.

A4 portrait, margins 36pt (printing package). Same hierarchy as the public page, print-safe:

- Pet block: name (Display), species/breed/sex, birth date, owner first name + initial.
- Table per section "Vacunación" and "Desparasitación" (two tables), columns: **Fecha** | **Biológico** | **Producto** | **Lote** | **Próxima / Vigencia** | **Estado** | **Aplicó (Dr(a). · Mat.)**; externas marked "Otra clínica" in the Aplicó column; anuladas omitted. ## Accessibility & Interaction Notes

- Status is never color-only: every `DosisEstadoChip` has icon + text; Vencida solid fill passes 4.8:1 with white; Próxima uses `primaryText` on `warningBg` (>= 7:1).
- Semantics: `DosisCard` announces "{Biológico}, {Dosis 2 de 3}, {estado}, aplicada el {fecha}, próxima el {fecha}, aplicó {Nombre}". Overflow: "Más acciones". `DuracionChips` expose "Duración 1 año, seleccionada". `ProximaPreview` is a live region (polite) announcing "Próxima: 05/10/2026".
- All touch targets >= 48dp (chips, tiles, rows, switch rows, action buttons).
- Animations <= 200 ms (disclosure, preview update fade); respect reduce-motion.
- Keyboard: date picker not typed; autocomplete overlay does not cover the Guardar button (scroll padding for keyboard inset).
- Public page: keyboard/screen reader semantics as above; page works without JS beyond data fetch (render server-side or fetch-and-render with `noscript` fallback "Active JavaScript para ver el carné.").
- Public page privacy: no pet/owner data in URL, token not guessable (>= 128 bits), `Referrer-Policy: no-referrer`, `Cache-Control: no-store`.
- Dark mode: app follows provisional dark tokens (reconfirm in Phase 8); status map must be re-derived there. Public page and PDF are light-only.
- Multi-vet: "Aplicó" attribution is always displayed on dose cards, public page and PDF (certificate). Pending alerts carry no vet marker (clinic-wide). Retired vet shows "(retirado)" in-app only; public page and PDF show name + matrícula without "(retirado)".
