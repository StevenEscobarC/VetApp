# Phase 5.1 Plan 05: Support contact and Inicio plan banner Summary

**Admins can ask support to activate or change the plan over WhatsApp from Mi plan (number from `--dart-define`, hidden when empty), and every vet gets one prioritized, soft plan banner on Inicio, with no price or payment wording anywhere. `flutter analyze` clean, `flutter test` 716/716 passing.**

## Accomplishments

- `soporte_config.dart`: `kSoporteWhatsapp` with no `defaultValue` and `kNombreApp` as the single place for the app name in new copy.
- `whatsapp_soporte.dart`: neutral message (clinic name, app name, plan of interest only), `wa.me` link built with `Uri.encodeComponent` (spaces are `%20`, never `+`), and the display formatter.
- Mi plan support block after "Qué incluye cada plan", three variants: admin with number (heading, body, "Plan de interés" chips Pro | Clínica preselected from the current plan, visible number, the only accent CTA "Escribir por WhatsApp"), admin without number (fallback text, no CTA), non-admin (explanation only). Tap tries `abrirEnApp`, then `abrir`, then shows "No pudimos abrir WhatsApp."
- `avisoPlanPara` implements UI-SPEC §3: solo lectura, gracia, pacientes 100 %, últimos 7 días (prueba Pro, prueba Clínica, plan pago, Beta con fecha), pacientes 80 %, veterinarios 80 % only when `miembros_max >= 5`. Admin and non-admin copy, hayColegas variants, "hoy" / "mañana" / "en n días" wording.
- `PlanBanner`: warningBg container, `primaryText` icon and title, "Ver mi plan" text button and tappable body both push `/mas/plan`, close button (tooltip "Descartar aviso") only on variants 4-6, one semantics node "{título}. {mensaje}. Ver mi plan", renders `SizedBox.shrink` while loading, on error and with no notice. The bottom spacing lives inside the banner, so Inicio has no extra gap when it is hidden.
- README documents `SOPORTE_WHATSAPP` (empty for the Play build) and the operational note "Antes de abrir el registro público: fijar beta_hasta con asignar_plan" with a SQL comment example.
