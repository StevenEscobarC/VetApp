# Phase 5.1 Plan 07: Clinica trial offer and seat limits in Equipo Summary

**The first invitation code in Gratis/Pro becomes the one-tap offer "Plan Clínica 30 días gratis, sin tarjeta": the sheet activates the trial and generates the code in the same server call, and every seat limit in Equipo opens an explanatory sheet instead of a raw error. `flutter analyze` clean, `flutter test` 783/783 passing.**

## Accomplishments

- `PruebaClinicaSheet`: icon circle, heading, body, three benefit rows (seat count from `miembros`, logo and protocolos, "Sin tarjeta y sin cobro automático"), grace sentence, single accent button "Activar y generar código" with loading state, "Ahora no" disabled while running. Returns `true` on success, `false` when the activation fails with `LimitePlan.miembros`, `null` on dismiss; any other error shows "No pudimos activar la prueba. Intenta de nuevo." and keeps the sheet open.
- `TeamFailure` carries `limite`; every repository `throw TeamFailure(...)` passes `limitePlanDe(e)`. `LP002` maps to "Tu plan no tiene cupo para más veterinarios." when generating and to the generic joining-vet message when using a code (no plan name or counts). The 4.1 substring rules are untouched.
- Equipo `_generar`: plan read (provider, then repository, else abort), trial sheet when `pruebaClinicaDisponible`, members `LimitePlanSheet` when the plan is full or when the server answers LP002 (also from inside the trial sheet), otherwise the existing flow. After a trial activation the snackbar reads "Prueba Clínica activa hasta el dd/mm/aaaa" and the invitation card is scrolled into view.
- "{n} de {m} veterinarios" under the button when the plan has 2 or more seats.
- `TeamActions` invalidates `miPlanProvider` after generating, retiring (shared `_refrescar`) and joining or creating a clinic (shared `_refrescarPerfil`).
