# Phase 5.1 Plan 09: Read-only colleagues on patients, history and carné Summary

**Colleagues in read-only now see a lock (not a dead or dimmed button) on every patient, history and carné write entry, tapping opens the 'Tu cuenta está en solo lectura' sheet, and a stale flag that still reaches the server (LP004) ends in the same sheet with the typed data kept. Reading, historia clínica, PDF, 'Compartir carné' and vaccine alerts are untouched. `flutter analyze` clean, `flutter test` 784/784 passing.**

## Accomplishments

- `ClienteFailure` and `ConsultaFailure` carry `limite` (`implements Exception, ConLimitePlan`, only `core/errors/limite_plan.dart` imported, no SDK in domain). Every `on PostgrestException` site in both repositories now throws `XFailure(_messageFor(e), limite: limitePlanDe(e))`; the message mapping handles `LP004` (read-only copy) and the other limits (generic "Esta acción no está incluida en tu plan.") before the existing code rules, which are unchanged.
- Consulta form and cliente save: first line of the `on XFailure` branch is the `manejarLimitePlan` fallback. The form stays open, fields keep their text, the loading flag resets in `finally`, no raw SnackBar.
- Cliente detail: 'Guardar cambios' (the screen's only accent CTA) keeps variant, size and accent; in read-only the icon becomes `lock_outline`, semantics read 'Guardar cambios, bloqueado, solo lectura', tap opens the sheet without calling `actualizar`. `_guardar` also pre-checks `asegurarEscritura`.
- Mascota file: 'Editar', 'Registrar peso', 'Nueva consulta' and 'Agendar cita' share one private `_controlEscritura` builder (same widget, variant, `expand`; icon via `iconoEscritura`; `ControlEscritura` semantics). Each handler starts with `asegurarEscritura(...)` (5 call sites including the photo flow) and checks `context.mounted` afterwards. Photo avatar: camera badge and gallery button show the lock, tapping opens the sheet instead of the capture. Weight sheet and photo upload both fall back to `manejarLimitePlan` on `MascotaFailure`.
- Carné: only 'Registrar dosis' is gated (pre-check inside `_registrar`, lock icon, semantics, accent kept). 'Compartir carné' has no gate and no lock; tests assert it opens the share sheet in read-only.
- Inicio: 'Vacunar' gets the same treatment; in read-only it opens the sheet instead of the search sheet, and the 05.1-05 banner is still shown above.
- Tests: new cases for all of the above (including semantics, "route did not change", "PDF export still shares", "historia clínica still expands", stale LP004 for consulta, cliente, weight and photo, and Beta behaving as before).
