## Phase Goal

ROADMAP Phase 8 goal (verbatim): "El veterinario ve un resumen operativo real al iniciar sesión, y toda la app refleja el diseño visual definitivo aprobado (terracota/crema, Caprasimo + Figtree), sin restos del dashboard mockeado."

Purpose: one theme change fixes Switch/Checkbox/FAB/dialog/date picker everywhere at once (BRAND-BASELINE suggested fix order 1). FABs, Switches and Checkboxes are themed, never replaced, so the existing FAB/Switch/Checkbox test finders keep passing (PATTERNS §17, §18).
Recorded decisions (Claude's discretion):
- textButtonTheme foreground: `AppColors.primaryText` when `colorScheme.brightness == Brightness.light`, `AppColors.primaryHover` in dark (primaryText on surfaceDark would fail contrast). This is the only place the theme reads `AppColors` by brightness; it is documented in a one-line comment.
- `AppButton` gains a square icon mode instead of a new shared widget (UI-SPEC scope: no new `lib/core/widgets` file): `cuadrado` (bool, default false), `lado` (double, default `AppSpacing.touchTarget`), `contenido` (Widget?, replaces the default icon/label child in any mode, e.g. icon + short label, or label + trailing chevron; the `label` still drives semantics), `botonKey` (Key?, forwarded to the inner Material button so `tester.widget<OutlinedButton>(find.byKey(...))` finders keep working). In square mode the inner button uses `padding: EdgeInsets.zero`, `minimumSize`/`fixedSize` `Size.square(lado)`, `expand` is ignored, and the child is wrapped in `Semantics(label: label)` (no Tooltip: a tooltip would steal the long-press that `TimeStepper` uses). Disabled outlined colors move to `outlinedButtonTheme` (`disabledBackgroundColor: colorScheme.surfaceContainerHighest`, `disabledForegroundColor: colorScheme.onSurfaceVariant`) so ajuste_rapido_botones needs no local style.
- Snackbar `behavior` is NOT changed (D-19: a floating snackbar moves layouts that existing tests tap).
- `ComingSoonScreen` deletion and its 2 doc comments are owned here (PATTERNS ownership hazard "pick one owner"). The clients/patients sweeps do not touch `clientes_list_screen.dart` or `pacientes_list_screen.dart`.
- The gate script lives in `tool/` (Dart convention for dev scripts). It extends the UI-SPEC SW-01 pattern with `.icon(` so `TextButton.icon(` is caught, and adds an SW-04 spacing gate (numeric literals in `EdgeInsets.*`, `SizedBox(height|width: N)` gaps, `BorderRadius.circular(N)`).
Output: themed core, token-clean core widgets, no ComingSoon, the gate script.
</objective>
