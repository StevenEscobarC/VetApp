## Phase Goal

ROADMAP Phase 8 goal (verbatim): "El veterinario ve un resumen operativo real al iniciar sesión, y toda la app refleja el diseño visual definitivo aprobado (terracota/crema, Caprasimo + Figtree), sin restos del dashboard mockeado."

Purpose: the Inicio branch stays mounted under `StatefulShellRoute`, so autoDispose alone never refreshes it (RESEARCH Pitfall 5).
Recorded decisions (Claude's discretion, PATTERNS §19):
- `CitaActions` (crear, actualizar, reasignar, cambiarEstado) and `RegistrarConsulta.call`: wrap the existing body in `try { <body unchanged> } finally { _ref.read(inicioRevisionProvider.notifier).incrementar(); }`. The existing invalidations and `citasRevisionProvider` increments keep their success-only semantics; only the new counter runs in `finally` (D-13 "en finally": a partial failure may still have written). `marcarRecordatorioEnviado` is not touched (it changes no Inicio number).
- `invalidarCobros`: one line inside the helper; its 7 callers already call it in `finally` (cobros_providers.dart l.111-119, 150-157).
- The two mascota screens increment on the success path next to `ref.invalidate(miPlanProvider)`: their RPCs are atomic (a failure creates nothing) and the widget may be unmounted in a `finally`. This is the documented exception to "finally".
- These 5 feature files are owned ONLY by this plan in Phase 8 (PATTERNS ownership hazards); no sweep plan edits them.
</objective>
