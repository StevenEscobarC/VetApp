<objective>
Fifth slice: the vet reminds clients by WhatsApp with one tap — individual button on card and detail, the "Recordar a todos los de mañana" serial flow, phone-type gating, and "Cómo llegar" to Google Maps for home visits (AGND-05; D-02, D-14, D-15, D-16 at use time).

Phase Goal (user story): **As a** veterinario independiente que atiende sin recepcionista, **I want to** ver mi agenda por día/semana, agendar citas para una o varias mascotas de un cliente, cambiar su estado, recibir un recordatorio en el celular, recordarle la cita al cliente por WhatsApp con un toque y registrar la consulta al completar la cita, **so that** gestione mi agenda y avise a mis clientes sin depender de una recepcionista ni de un computador.

Purpose: After this plan the vet can notify clients without typing anything. External launches go through an injectable `LanzadorExterno` so widgets are testable without the platform.

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| App -> external apps (WhatsApp, Maps) via intents | Client data (name, pets, address, phone) leaves the app in a URL, user-initiated only |
| Stored text -> URL | Names/addresses typed by users are embedded into outbound URLs |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-04-31 | Tampering (URL/intent injection) | whatsappUri / mapsUri | mitigate | Fixed https hosts; every dynamic component percent-encoded with Uri.encodeComponent; phone reduced to digits by numeroWhatsApp; unit tests for '#', '&', '?', accents |
| T-04-32 | Information disclosure | Sending client data to WhatsApp | accept | Only on an explicit vet tap to the client's own number (no server/API, DIFF-01 excluded); message contains only cita data the client already knows |
| T-04-33 | Spoofing | Return detection marking a reminder as sent | accept | Requires paused/hidden -> resumed while waiting; worst case is a wrongly marked flag, reversible via Deshacer/manual; no security impact |
| T-04-34 | Elevation of privilege | Location permission | mitigate | 'Cómo llegar' passes the address to Maps; no location permission requested (D-02) |
</threat_model>
